01 · Build

独立站搭建

核心服务。从零搭一个能收款、能上广告、能持续运营的店铺。平台按需选：Shopify 适合托管开店，WordPress/WooCommerce 适合要完全自主的，也可做纯展示+询盘的 B2B 站。

适合：想开第一个外贸站的新手；已有店铺想换新站的卖家；做品牌出海的企业。

包含内容

  • 店铺创建与基本设置（Shopify / WordPress / 自建）
  • 主题选择与装修（电脑 + 手机适配）
  • 首页、产品页、关于页、联系页、政策页
  • 产品上架（标题、描述、价格、库存、分类）
  • 收款方式配置（PayPal / 信用卡）
  • 物流与运费模板设置
  • 域名绑定与基础邮箱配置
  • 基础 SEO：标题、描述、URL、站点地图
  • 交付图文教程 + 后台使用教学
02 · Design

主图 · 详情页设计

跨境电商的转化，一半靠图。按平台规范做白底图、场景图、卖点图与详情页排版，让产品在搜索结果里跳出来。

适合：产品图不达标、点击率低、详情页像"批发列表"的卖家。

包含内容

  • 产品主图（白底 / 场景 / 卖点）
  • 详情页长图排版（卖点逻辑 + 视觉动线）
  • 尺寸规范适配（Shopify / 亚马逊 / 独立站）
  • 批量出图（同一产品多角度、多色）
  • 与建站打包时：主图直接上架
03 · Ads

广告制作

广告素材 + 文案 + 落地页建议，从"会投钱"到"投对钱"。社媒（Facebook / Instagram / TikTok）与搜索（Google）都覆盖。

适合：准备投放但没素材；投放效果差想换素材；预算有限想把钱花在刀刃上。

包含内容

  • 广告主图 / 视频封面设计
  • 广告文案（多版本 A/B）
  • 落地页跳转建议（对应广告的页面）
  • 素材尺寸适配各平台
  • 投放结构建议（可选）
04 · Operations

店铺运营托管

店铺上线只是开始。上新、调价、客服、订单、数据复盘，按月托管，你只管出货和发货。

适合：有货没时间运营；运营三天打鱼两天晒网；想系统化把店铺做起来。

包含内容

  • 产品上新与下架管理
  • 价格与库存调整
  • 客服话术模板与常见问题处理
  • 订单状态跟进
  • 月度数据复盘与优化建议
  • 竞品与市场信息速递
05 · SEO & Payment

SEO · 收款 · 合规配置

让网站能被搜到、能收钱、不出合规问题。通常是建站的组成部分，也可以单独补课。

适合：老站没有做 SEO；收款老被拒；缺少政策页怕被封店。

包含内容

  • 页面标题 / 描述 / URL 优化
  • 产品关键词建议
  • PayPal / Stripe / 信用卡收款配置
  • 隐私政策、服务条款、退换货政策页
  • 结账流程检查与修复
06 · Maintain & Advise

改版 · 维护 · 顾问

老站改版、功能增补、日常维护，以及按品类给建站与选品建议。老客户优先排期。

适合：已有站想升级；功能要加但不知道找谁；对品类和市场没底。

包含内容

  • 老站改版（视觉 / 结构 / 移动端）
  • 功能增补（评论、多语言、订阅等）
  • 日常问题排查与修复
  • 品类与市场建议（基于公开数据）
  • 按需出小方案，先报价后开工
