Under the hood · how it works

Production-grade architecture, not a chat script

1

Multi-Agent Orchestration

Supervisor - Worker
  • Supervisor classifies intent and dispatches tasks (rules + LLM double-check)
  • SEO / Inquiry / Quote / Content specialists work independently
  • Verifier re-computes every number before replying — no drift
  • Full trace log, every step replayable
2

Deterministic Engine

zero hallucination on numbers
  • Scoring, pricing and quotes come from deterministic formulas
  • The model only explains and attributes — it never produces figures
  • Evidence-gated: no data → framework + test plan, no invented "optimal price"
  • Strict copy rules: numbers are quoted verbatim, never rewritten
3

RAG Rule Base

acts by the rules
  • Inquiry SLA, pack discounts, SEO and content standards
  • Keyword + category retrieval; auto-degrades with explanation when nothing matches
  • Answers cite their source, visible in the trace
4

Evaluation Loop

test set + metrics + attribution
  • 52-case synthetic suite (standard + edge cases)
  • Intent accuracy / decision compliance / calc error rate
  • Bad-case attribution across rules, data and model layers
  • Rule vs LLM-enhanced paths compared side by side
